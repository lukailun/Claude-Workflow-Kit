## [ERROR-1] 严禁对可能为假值的数据使用 && 渲染

当变量可能为空字符串或数字 0 时严禁该写法：`{value && <Component />}`。
空字符串和数字 0 属于 JavaScript 假值，但在 JSX 中可以被渲染。React Native 会把它们当作纯文本渲染在 <View> 等非文本标签，导致应用直接崩溃。

### 错误示例（count=0 或 name="" 时崩溃）

```tsx
function Profile({ name, count }: { name: string; count: number }) {
  return (
    <View>
      {name && <Text>{name}</Text>}
      {count && <Text>{count} items</Text>}
    </View>
  )
}
// name 为 "" 或 count 为 0 时，假值被直接渲染，导致崩溃
```

### 正确示例 1：三元表达式，不满足时返回 null

```tsx
function Profile({ name, count }: { name: string; count: number }) {
  return (
    <View>
      {name ? <Text>{name}</Text> : null}
      {count ? <Text>{count} items</Text> : null}
    </View>
  )
}
```

### 正确示例 2：强转为布尔值再做 && 判断

```tsx
function Profile({ name, count }: { name: string; count: number }) {
  return (
    <View>
      {!!name && <Text>{name}</Text>}
      {!!count && <Text>{count} items</Text>}
    </View>
  )
}
```

### 最优方案：提前 return（可读性最优）

```tsx
function Profile({ name, count }: { name: string; count: number }) {
  if (!name) return null

  return (
    <View>
      <Text>{name}</Text>
      {count > 0 ? <Text>{count} items</Text> : null}
    </View>
  )
}
```

提前返回的写法可读性最高。如果需要在行内写条件判断，优先使用三元表达式，或者显式的布尔值校验。
