## [ERROR-3] 必须使用国际化

所有面向用户的文案必须通过国际化方案管理，禁止硬编码中文或英文字符串。
项目使用 `useI18n` hook 进行国际化，翻译文件存放在 `src/Languages/` 目录下。

### 静态文案

#### 错误示例

```tsx
// 硬编码中文
function Profile() {
  return (
    <View>
      <Text>绑定手机</Text>
      <Text>未绑定</Text>
    </View>
  )
}
```

```tsx
// 硬编码英文
function Profile() {
  return (
    <View>
      <Text>Bind Phone</Text>
      <Text>Not Bound</Text>
    </View>
  )
}
```

#### 正确示例

```tsx
import useI18n from '@/Hooks/useI18n'

function Profile() {
  const { t, l } = useI18n()
  return (
    <View>
      <Text>{t(l.account_setting.bind_phone)}</Text>
      <Text>{t(l.account_setting.not_bound)}</Text>
    </View>
  )
}
```

### 带模板参数的翻译

当翻译文案中包含动态内容时，必须使用模板参数：

翻译文件 (`zh.json`)：
```json
{
  "chat": {
    "days_count": "已聊 {{count}} 天"
  }
}
```

翻译文件 (`en.json`)：
```json
{
  "chat": {
    "days_count_one": "{{count}} Day Chatted",
    "days_count_other": "{{count}} Days Chatted"
  }
}
```

#### 错误示例

```tsx
// 硬编码拼接复数
function ChatInfo({ days }: { days: number }) {
  return <Text>已聊 {days} 天</Text>
}
```

```tsx
// 手动判断复数逻辑
function ChatInfo({ days }: { days: number }) {
  const { t, l } = useI18n()
  const text = days === 1 ? `${days} Day Chatted` : `${days} Days Chatted`
  return <Text>{text}</Text>
}
```

```tsx
// 翻译 key 中硬编码后缀
function ChatInfo({ days }: { days: number }) {
  const { t, l } = useI18n()
  const suffix = days === 1 ? '_one' : '_other'
  return <Text>{t(`chat.days_count${suffix}`, { count: days })}</Text>
}
```

#### 正确示例

```tsx
import useI18n from '@/Hooks/useI18n'

function ChatInfo({ days }: { days: number }) {
  const { t, l } = useI18n()
  return <Text>{t(l.chat.days_count, { count: days })}</Text>
}
```

`useI18n` 会根据传入的 `count` 参数和当前语言的复数规则，自动选择 `_one` 或 `_other` 对应的翻译。不要手动拼接 key 或自行判断复数。

### 何时可以豁免

以下场景不需要国际化：

| 场景 | 原因 |
|------|------|
| 日志、调试信息 | 不面向用户 |
| 技术标识符（key、id、className） | 非文案内容 |
| 第三方库要求的固定字符串 | 无法控制 |
| URL、协议名称 | 不需要翻译 |
