## [WARNING-3] 列表中头像优先使用缩略图

在列表场景中展示用户头像时，应优先使用缩略图，仅在缩略图不可用时回退到原图。

### 错误示例

```tsx
<AvatarWithTagIcon
  avatar={item.avatar}
  size={72}
/>
```

### 正确示例

```tsx
<AvatarWithTagIcon
  avatar={item.avatar_thumb ?? item.avatar}
  size={72}
/>
```

### 注意事项

1. 仅限列表场景：个人主页、资料详情页等非列表场景直接使用原图，不需要此规则
2. 回退不可省略：`avatar_thumb` 可能为 `undefined`，必须用 `??` 做回退，避免头像不显示
