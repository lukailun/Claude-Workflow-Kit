## 环境变量 + CLI 实现

参考 openwiki 项目，为 CWK 实现了分层环境变量和统一 CLI 入口。

### 环境变量系统

- **分层加载**: Shell export > 项目级 `.dev-kit/.env` > 用户级 `~/.dev-kit/.env`
- **用户级** (`~/.dev-kit/.env`): 个人凭据（API keys、tokens），跨项目共享，权限 0o600
- **项目级** (`.dev-kit/.env`): 项目配置（base URLs、project IDs），因项目而异
- **核心文件**: `packages/shared/src/env/env-manager.ts` — loadEnv/saveUserEnv/saveProjectEnv/parseEnv/formatEnv/getEnvDiagnostics
- **常量定义**: `packages/shared/src/env/env-constants.ts` — USER_ENV_KEYS / PROJECT_ENV_KEYS
- **目录结构**: `packages/shared/src/env/home-dir.ts` — ~/.dev-kit/ 定义
- **向后兼容**: 现有 `requireEnv`/`optionalEnv`/`get-*-from-env` 无需修改，env-path.ts 自动加载

### CLI

- **新包**: `@cwkit/cli`（`packages/cli/`）
- **入口**: `bin/cwkit.js` 使用 `--import tsx` 子进程运行 TS 入口（tsx v4+ 不支持 register() API）
- **命令**: feature/feat, experimental/exp, hotfix, release, commit, mr, submit, publish-release, publish-hotfix, receipt, yolo, config list/init
- **配置命令**: `cwkit config list` 显示所有 env 变量状态，`cwkit config init` 创建模板文件
- **根 package.json**: 所有 scripts 委托到 `pnpm cwkit <command>`
